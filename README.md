# ZMK Configuration for Saturn

![Keyboard Layout](keymap-drawer/saturn.svg)

_(keymap image generated by [caksoylar/keymap-drawer](https://github.com/caksoylar/keymap-drawer))_

Saturn 是一个分体键盘：

- **左手（外设）**：4 行 6 列矩阵（row0–row3, col0–col5）+ 1 个直接引脚按键 + 1 个 EC11 编码器 + WS2812 RGB underglow（chain=1）
- **右手（中央）**：4 行 7 列矩阵（row0–row3, col6–col12）+ PAW3222 轨迹球
- 主控：**nRFMicro 1.3（nrfmicro_13）**
- 固件：ZMK（[DYA Studio fork](https://github.com/cormoran/zmk/tree/v0.3-branch%2Bdya)，基于 v0.3 分支），支持 [ZMK Studio](https://zmk.dev/docs/features/studio) / DYA Studio 在线改键

## 目录结构

```
├── boards/shields/saturn/        # 键盘 shield 定义
│   ├── Kconfig.shield / Kconfig.defconfig
│   ├── saturn.dtsi               # 公共定义（矩阵变换、编码器、物理布局）
│   ├── saturn-layouts.dtsi       # 物理布局（键位坐标）
│   ├── saturn_left.overlay       # 左手：矩阵 + direct pin + 编码器 + RGB
│   ├── saturn_left.conf
│   ├── saturn_right.overlay      # 右手：矩阵 + 轨迹球监听
│   ├── saturn_right.conf         # Studio / DYA 模块配置
│   ├── trackball.dtsi            # PAW3222 SPI 配置
│   └── saturn.zmk.yml
├── config/
│   ├── west.yml                  # ZMK 依赖（DYA fork + paw3222 驱动 + DYA 模块）
│   ├── saturn.keymap             # 键位
│   ├── saturn.json               # 键位坐标（keymap-drawer 使用）
│   └── saturn.conf               # 全局配置
├── build.yaml                    # 构建矩阵（GitHub Actions）
├── keymap_drawer.config.yaml     # keymap-drawer 配置
└── .github/workflows/            # 固件构建 + keymap 绘制
```

## 接线（pro micro 引脚）

| 功能 | 引脚 |
| --- | --- |
| 左手矩阵列 | D1 D0 D2 D3 D4 D5 |
| 左手矩阵行 | D6 D7 D8 D9 |
| 左手直接引脚 | D21 |
| 左手编码器 | A=D19, B=D18 |
| 左手 WS2812 数据 | D20 (SPI3 MOSI) |
| 右手矩阵列 | D1 D0 D2 D3 D4 D5 D6 |
| 右手矩阵行 | D7 D8 D9 D21 |
| PAW3222 SCK / SDIO | D20 / D19 (SPI1) |
| PAW3222 CS / IRQ | D18 / D16 |

> 注意：此表按原 Shield Wizard 生成的接线意图整理（原仓库 overlay 中 SPI 的 pinctrl 与实际引脚注释不符，已按注释/向导数据修正为 D20/D19）。请对照你实际焊接的引脚确认。

## 构建

推送到 `main` 分支后 GitHub Actions 自动构建，固件在 Actions 页面下载：

- `saturn_left`（左手，外设）
- `saturn_right`（右手，中央，含 ZMK Studio RPC）
- `settings_reset`（清空设置）

## DYA Studio / ZMK Studio

- 右手固件内置 Studio 支持（USB 连接电脑后打开 <https://studio.zmk.dev> 即可在线改键、调整轨迹球参数与编码器行为）。
- 编码器使用 `zmk,behavior-runtime-sensor-rotate`，可在 Studio 中实时修改滚动/音量行为。
- 轨迹球经 `zmk,input-listener` + runtime input processor 处理，灵敏度等可在 Studio 中调整。
- 相关模块：`zmk-module-settings-rpc`、`zmk-module-ble-management`、`zmk-module-runtime-input-processor`、`zmk-behavior-runtime-sensor-rotate`。

## Keymap Drawer

`config/saturn.keymap` 变更并推送后，`.github/workflows/keymap_drawer.yml` 会自动重新生成 `keymap-drawer/saturn.svg`。也可本地执行：

```sh
pip install keymap-drawer
keymap parse -c keymap_drawer.config.yaml -j config -z config/saturn.keymap -o keymap-drawer/saturn.yaml
keymap draw keymap-drawer/saturn.yaml -o keymap-drawer/saturn.svg
```

## 注意事项

- **轨迹球 CPI**：PAW3222 驱动要求 CPI 范围 608–4826，当前配置 1600（原 pmw3610 的 600 不受支持）。可在 `boards/shields/saturn/trackball.dtsi` 中修改。
- **轴方向**：监听器默认带 `INPUT_TRANSFORM_XY_SWAP`（保留原 pmw3610 `swap-xy` 的安装方向）。若轨迹球方向不对，可修改 `saturn_right.overlay` 或在 Studio 中调整。
- **paw3222 驱动分支**：`west.yml` 固定使用 `tokyo2006/zmk-driver-paw3222` 的 `v0.3` 分支（`pixart,paw3222` compatible）；其 `main` 分支已迁移到 v0.4 的 `xinta` 命名空间，与 v0.3 DYA fork 不兼容。
- **RGB 供电**：左手启用了 `CONFIG_ZMK_EXT_POWER`（nRFMicro 1.3 的 EXT_POWER 控制引脚），若灯带不亮可检查该引脚供电。
- 自动休眠默认关闭（轨迹球键盘不建议开启）。
